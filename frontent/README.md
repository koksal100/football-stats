# Football Stats — Frontend

React 19 + Vite 7 ile geliştirilmiş futbol istatistikleri arayüzü.

## Kurulum

```bash
npm install
npm run dev
```

Varsayılan adres: http://localhost:5173

Backend adresi varsayılan olarak `http://localhost:8080`'dir. Değiştirmek için:

```bash
# .env
VITE_API_URL=http://localhost:8080
```

## Komutlar

| Komut | Açıklama |
|---|---|
| `npm run dev` | Geliştirme sunucusu |
| `npm run build` | Production build (`dist/`) |
| `npm run preview` | Build çıktısını önizleme |
| `npm run lint` | ESLint kontrolü |

Projenin tamamı ve backend kurulumu için kök dizindeki [README](../README.md) dosyasına bakın.
